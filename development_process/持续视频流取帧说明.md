# 持续视频流取帧

系统已统一改为从 USB 连接上的 scrcpy H.264 视频流取帧，不再每次调用 `adb exec-out screencap -p`。人工采集、模型推理、有限尝试训练、自主展示、视觉校准和八方向面板都使用同一套取帧接口；原有启动命令不变。

## 工作方式

```text
小车摄像头 → 手机 App → scrcpy 持续编码 → USB / ADB 转发
                                                ↓
                                     后台持续解码，保留最新一帧
                                                ↓
                              模型决策 → 短按并释放 → 等待新帧
```

每个程序首次取帧时启动一次 scrcpy 视频服务，之后复用连接。后台只保留最新画面，不积压待处理帧；动作结束后的读取会等待取帧请求之后的新帧，避免直接用动作前缓存再次决策。退出时清理视频连接、服务进程及端口转发。

当前配置为 H.264、最长边 1280 像素、最高 30 fps、码率 4 Mbps；导航输入仍缩放至宽 960 像素。触控坐标使用手机原始逻辑显示尺寸，不使用压缩后的视频尺寸，因此原来的方向标定继续有效。手机需保持横屏，旋转后应退出并重新启动。

这里传输的是**手机屏幕视频流**，其中包含 App 显示的小车第一视角，并不是直接连接小车摄像头。小车到手机的延迟仍存在，屏幕有新帧也不能证明 App 内摄像头画面正在更新。

## 安装与只读测速

在项目目录打开 PowerShell：

```powershell
.\.venv\Scripts\python.exe -m pip install -r .\requirements-vision.txt
.\.venv\Scripts\python.exe .\phone_video_stream.py --frames 60
```

新增的 PyAV 解码依赖已安装到本机 `.venv`。需要已安装 scrcpy，手机已允许 USB 调试，且处于解锁后的横屏小车 App。默认自动寻找 ADB；如遇到缺少 scrcpy 服务文件的提示，用 `--adb 'scrcpy安装目录\adb.exe'` 指定与 `scrcpy.exe`、`scrcpy-server` 位于同目录的 ADB。

测速入口不发送任何触控。它显示首次启动耗时、原始触控尺寸、编码尺寸、连续取帧率和平均帧年龄。首次启动包含服务推送与初始化，不代表后续每帧耗时。帧年龄通过视频时间戳映射估算，不能作为小车摄像头到电脑的完整延迟。

## 继续训练或展示

```powershell
# 有限尝试：每次动作后等待人工评价或纠正
.\.venv\Scripts\python.exe .\rl_navigation.py --mode trial --pulse-ms 500 --steps 10 --seconds 180

# 自主展示：点击 AUTO 后连续由系统决策
.\.venv\Scripts\python.exe .\rl_navigation.py --mode showcase --pulse-ms 500 --steps 10 --seconds 60
```

按压时间仍为 500 ms。持续视频流减少反复启动截图和 PNG 编解码的开销，但实际决策周期还包括触控调用、模型计算、日志写盘与等待新帧；不能保证取帧间隔严格等于按压时间，也不等于每秒控制 30 次。

训练和展示仍保留原来的动作前后图片、指令与人工校准日志。**不再逐次截图取画面，不代表关闭图片留档。** 本次未改变训练规则、已有示范数据或策略文件。

## 日志与异常说明

- `capture_seconds` 保留原字段名；现在表示估算的视频帧年龄加取帧处理耗时，不再表示一次 ADB 截图命令耗时。旧日志和新日志不能按同一含义直接比较。
- `actual_capture_interval_ms` 使用动作前后视频帧时间差；`command_elapsed_ms` 仍记录控制命令耗时。
- USB 断开、解码失败或画面旋转会报错，导航停止追加动作。暂时没有新帧时等待，超时后报错；不会反复拿最后一张缓存图继续行驶。静止屏幕可能不产生新编码帧，也会触发此等待。
- 已发送的短按会按原定时长释放；视频取帧不负责改变触控持续时间。不要同时开启多个小车控制程序。

已通过模拟协议、实际 H.264 编解码、新帧等待、断流和触控尺寸映射的自动测试，覆盖旧版帧头和本机 scrcpy 4.1 的 session 帧头。USB 实测已完成视频服务连接与 4.1 握手；手机当时处于息屏、竖屏状态，未输出图像，尚未测得帧率或提速幅度。请先解锁手机、打开横屏小车 App，再运行上述只读测速命令。
